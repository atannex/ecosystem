# Atannex Ecosystem

Adds search to Laravel models without a separate search server. You say which columns and related records are searchable, and the package finds and ranks matching records. People can search with quotes for exact phrases, a minus sign to leave words out, and filters such as field names or number ranges. It can search several kinds of records at once and highlight the matching words.

## Install

```bash
composer require atannex/ecosystem
```
